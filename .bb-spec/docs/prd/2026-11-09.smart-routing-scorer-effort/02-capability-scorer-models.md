# 能力表列出打分模型

## 用户故事
### P0：作为管理员，我想在「模型思考能力」里补上打分模型支持的档位，以便内置表里没有的打分模型也能选 none 关掉思考

**用例（主路径）**
- 场景：auto-gpt 三个档位用 gpt-5.6-luna、gpt-6.1-terra、gpt-6.1-sol，打分模型是 deepseek-v4.1-flash（不在内置表里）。
- 操作：管理员打开「系统设置 → 请求策略 → 智能路由」，看「模型思考能力」表，点 deepseek-v4.1-flash 一行的「覆盖」，勾上 none、low、high、max，保存。
- 预期：表里有 4 行，标题旁的数字是 4；deepseek-v4.1-flash 一行原来是「未确认」和描边的 low / medium / high，覆盖后来源变成「已覆盖」，档位是 none、low、high、max；回到编辑弹窗的「打分」页签，下拉里能选 none，「能力未确认」标签消失。

**用例（边界 / 异常）**
- 场景：打分模型和简单档都是 gpt-5.6-luna。
- 预期：表里 gpt-5.6-luna 只有一行。
- 场景：顾问模型是 gpt-6-astra，没有档位或打分用到它。
- 预期：表里没有 gpt-6-astra。

## 约束
- C1：表格列出所有虚拟模型三个档位和打分用到的模型，同一个模型只列一行；顾问模型不因为是顾问而列出。标题旁的数字等于表格行数。
- C2：打分模型那一行的来源、支持的档位、操作（覆盖 / 修改 / 恢复内置）和档位模型的行完全一样，覆盖后对编辑弹窗里打分的下拉同样生效。

## 验收
- [ ] C1：按主路径场景配置 → 表格 4 行、数字 4；打分模型与简单档同为 gpt-5.6-luna → 只有一行；顾问 gpt-6-astra 不出现在表里。
- [ ] C2：覆盖 deepseek-v4.1-flash 为 none、low、high、max 并保存 → 该行来源「已覆盖」；编辑弹窗「打分」页签下拉列出 none、low、high、max，没有「能力未确认」标签；点「恢复内置」→ 回到「未确认」和 low、medium、high。

## 验证路径
1. 打分模型设为 deepseek-v4.1-flash → 「模型思考能力」表多出这一行，来源「未确认」。
2. 覆盖成支持 none、low、high、max → 编辑弹窗打分下拉出现 none。
3. 点「恢复内置」→ 打分下拉回到 low、medium、high，并显示「能力未确认」。
