# 用户统计默认按 Token 显示

## 用户故事
### P0：作为管理员，我想要打开用户统计时直接看到 Token 用量，以便不用每次都手动切换

**用例（主路径）**
- 场景：管理员小王想看最近 7 天哪些用户用得最多。
- 操作：打开数据看板，点「用户统计」。
- 预期：指标切换选中的是「Token」；「用户消耗排行」和「用户消耗趋势」两张图都按 Token 用量画。

**用例（切回金额）**
- 场景：小王想对比各用户花了多少钱。
- 操作：在「用户统计」里点「金额」。
- 预期：指标切换选中「金额」，两张图都改按金额画。

**用例（重新进入）**
- 场景：小王上次切到了「金额」，然后刷新了页面。
- 操作：刷新后再打开「用户统计」。
- 预期：指标切换又回到「Token」。

## 约束
- 打开「用户统计」时，没有做过任何选择 → 指标切换选中「Token」，两张图按 Token 用量画。
- 点「金额」→ 两张图按金额画；再点「Token」→ 又按 Token 用量画。
- 刷新页面后重新打开「用户统计」→ 指标切换回到「Token」，不记住上次的选择。

## 验收
- [ ] 首次打开「用户统计」，指标切换选中「Token」，排行图和趋势图都显示 Token 用量。
- [ ] 点「金额」后两张图都显示金额；再点「Token」后两张图都恢复显示 Token 用量。
- [ ] 选「金额」后刷新页面，再打开「用户统计」，指标切换选中「Token」。

## 验证路径
1. 管理员登录，打开 `/dashboard/users` → 指标切换选中「Token」，图表数值是 Token 数。
2. 点「金额」→ 图表数值变成金额。
3. 刷新页面 → 指标切换选中「Token」。
