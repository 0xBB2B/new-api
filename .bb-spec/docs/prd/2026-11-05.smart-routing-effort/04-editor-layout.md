# 配置弹窗改版

## 用户故事
### P0：作为管理员，我想一次只看一组设置、关键字段一眼看全，以便配虚拟模型时不被无关信息干扰

**用例（主路径）**
- 场景：管理员编辑 auto-gpt。
- 操作：在智能路由页点 auto-gpt 的编辑图标，点左栏「档位」，再点三档切换里的「困难」。
- 预期：右栏只显示困难档的三行：困难档模型、思考力度、分组顺序；不用滚动就能看全。三档切换的「普通」后面带「默认」标签，右边是「默认档 [普通档]」。

**用例（边界 / 异常）**
- 场景：打分模型没设置价格，普通档的分组渠道接收不了所勾格式。
- 操作：点「保存」。
- 预期：弹窗不关，自动切到左栏「打分」，打分模型下面写红字；左栏「打分」「档位」都带红点和「1 个错误」；进「档位」后「普通」也带红点。

## 约束
- C1：弹窗宽度用 `max-w-5xl` 一档。顶部一行横跨整个弹窗，只有「名称」（必填）和「接口」两项。接口是三个可多选的按钮「Responses · Chat · Anthropic」，选中时主色描边、浅色底、主色文字；悬停每个按钮显示完整路径（Responses 的提示里写明压缩请求跟着它）。
- C2：顶部下面分左右两栏。左栏竖排三个 Tab：「打分」「档位」「顾问」，每个 Tab 显示名字和一行摘要：打分、顾问写所选模型名，没选写「未设置」；档位写「<已设置的档数>/3 已设置」。选中的 Tab 用和接口按钮相同的主色样式。左栏支持键盘方向键切换，读屏软件读作标签页。手机宽度下，左栏变成顶部横排的三个 Tab。
- C3：右栏每行左边是字段名，右边是控件。说明文字一律收进字段名旁的 ⓘ，悬停才显示；框里只显示出错的红字和「该模型不支持思考力度，请求时不发送思考参数」这类状态文字。
- C4：「打分」Tab 有三行：打分模型（ⓘ「用户每发一条新消息调用一次。费用按打分模型的价格，单独记一条消费记录」）、超时（毫秒）（ⓘ「超时就用默认档」）、分组顺序。
- C5：「档位」Tab 顶部一行：左边是三档切换「简单 · <模型名>」「普通 · <模型名>」「困难 · <模型名>」，被设成默认档的那一档后面带「默认」小标签，悬停每档显示「<模型名> · <力度摘要>」；右边是小下拉「默认档」（ⓘ「下面 4 种情况都用默认档：打分失败或超时；打分把握不足；工具续跑时没有会话；选中的档位没有渠道」），默认普通档。下面三行：<档>模型（ⓘ「用户每发一条新消息，打分后落到其中一档」）、思考力度、分组顺序。
- C6：「思考力度」压成一行：先是三选一的「不覆盖 · 固定 · 跟随打分」；选「固定」时同一行后面跟一个小下拉；选「跟随打分」时后面跟「[最低] ～ [最高]」两个小下拉。ⓘ 写「不覆盖：保留客户端传来的值，模型不支持这一档时自动换成最接近的档位。跟随打分：按打分的「要想多深」取值（低→low、中→medium、高→high），再限制在最低和最高之间；打分失败时用最高。力度下拉只列这个模型支持的档位」。
- C7：「顾问」Tab 有三行：顾问模型（ⓘ「同一段对话里，用户连续多条消息表示不满意时，这一轮交给顾问模型回答」）、连续不满意几次后交给顾问、分组顺序；没有思考力度。
- C8：「高级设置」默认收起，放在整个弹窗最底部、横跨两栏，内容和一期相同。底部是「取消」「保存」。
- C9：三个 Tab 里的「分组顺序」都是同一种一行紧凑样子：带序号的小标签（如「1 subscription」「2 api」），每个标签左边一个拖动把手、右边一个 ×，最后一个「＋」，点开是可选分组的下拉。
  - 拖动标签调整顺序，鼠标停在标签上时光标变成抓手；只有一个分组时不能拖。
  - 键盘聚焦标签后按 Alt + ← / → 移动顺序。
  - 满 5 个时「＋」变灰；没选分组时只显示「＋ 添加分组」；这一行出错时描红，下面写红字。ⓘ 写「按顺序尝试这些分组，前一个分组的渠道都失败了再试下一个；最多 5 个。拖动分组调整顺序」。
  - 这是给现有分组顺序组件加的紧凑样式；密钥抽屉里的分组顺序样子和行为不变。
- C10：新建虚拟模型时停在「打分」Tab，接口只选 Responses，分组为空。编辑时停在「打分」；从表格编辑图标进入时同样停在「打分」。
- C11：点「保存」后，后台检查项和提示文字沿用一期（名称、模型、分组、渠道、价格、数字范围），另加「至少选择一种接口」和多接口的渠道检查。有错时弹窗不关：有错的左栏 Tab 带红点和「<N> 个错误」，档位里有错的那一档也带红点；自动切到第一个有错的地方，顺序是打分 → 档位（简单 → 普通 → 困难）→ 顾问。名称、接口的错误写在顶部各自下面，不给左栏加红点。
- C12：在 1100px 高的浏览器窗口里，每个 Tab 的全部字段不用滚动就能看全。
- C13：智能路由页「虚拟模型」表格：名称列第二行写「<所勾接口的简称，用 / 连接> 接口」，例如「Responses / Anthropic 接口」；三个档位列第二行写「<力度摘要> · <分组顺序，用 → 连接>」。力度摘要是「不覆盖」「固定 medium」「跟随打分 medium～xhigh」或「不支持思考」。格子太窄时末尾省略，悬停显示全文。
- C14：新增文字都有七种界面语言的翻译。

## 验收
- [ ] C1：弹窗顶部只有名称和接口；接口三个按钮可以同时选中多个，选中样式和预览一致，悬停显示完整路径。
- [ ] C2：左栏三个 Tab 的摘要随填写变化（选了打分模型后摘要变成模型名，档位摘要从「0/3 已设置」变到「3/3 已设置」）；方向键能切换 Tab；400px 宽时左栏变成顶部横排。
- [ ] C3：弹窗里除了出错红字和不支持思考的灰字，看不到别的说明文字；悬停每个 ⓘ 显示对应说明。
- [ ] C4：「打分」Tab 只有打分模型、超时、分组顺序三行，ⓘ 文字和约束一致。
- [ ] C5：「档位」Tab 的三档切换显示档名加模型名，默认档带「默认」标签；改「默认档」下拉后标签跟着移动。
- [ ] C6：思考力度在「固定」「跟随打分」之间切换时，后面的小下拉跟着变成一个或两个。
- [ ] C7：「顾问」Tab 只有三行，没有思考力度。
- [ ] C8：高级设置默认收起，在弹窗最底部；展开后的字段和默认值与一期相同。
- [ ] C9：三个 Tab 的分组都是一行小标签；拖动能调整顺序；Alt + ← / → 能移动；只有一个分组时拖不动；第 5 个之后「＋」变灰；密钥抽屉里的分组顺序和改版前一样。
- [ ] C10：新建时停在「打分」，接口只选 Responses，分组只显示「＋ 添加分组」。
- [ ] C11：构造「打分模型没价格 + 普通档渠道拒收所勾格式」→ 切到「打分」，红点与「1 个错误」出现在「打分」「档位」和「普通」上；名称重名 → 红字在名称下面，左栏没有红点。
- [ ] C12：在 1100px 高的窗口打开 9 种状态（新建、编辑各档、顾问、各种出错）→ 弹窗内容区都不出现滚动条。
- [ ] C13：表格里 auto-gpt 名称下写「Responses / Anthropic 接口」，困难档第二行写「跟随打分 medium～xhigh · subscription → api」。
- [ ] C14：切换七种界面语言 → 新增文字都有翻译。

## 验证路径
1. 新建虚拟模型 → 停在「打分」，接口只选 Responses。依次填打分、三档、顾问，左栏摘要随之变化。
2. 在困难档选「跟随打分 medium～xhigh」，把 api 分组拖到 subscription 前面，保存并保存更改 → 表格第二行显示新的力度和分组顺序。
3. 制造两个错误后保存 → 自动切到第一个有错的 Tab，红点位置和预览一致。
4. 拿实际弹窗和确认过的预览逐个状态对比：布局、文案、ⓘ 提示、各种出错的样子、深浅色。
