# 模型思考能力

## 用户故事
### P0：作为管理员，我想知道档位里每个模型支持哪几档思考力度，并能改正不对的，以便配出来的力度都能用

**用例（主路径）**
- 场景：auto-gpt 三档用了 gpt-5.4-mini、gpt-5.5、gpt-5.6-sol，auto-chat 三档用了 gpt-4.1、glm-5.1、gpt-5.6-sol。
- 操作：打开「系统设置 → 请求策略 → 智能路由」。
- 预期：「虚拟模型」卡片下面有「模型思考能力」卡片，列出 5 个模型：gpt-5.4-mini、gpt-5.6-sol 来源「内置」；gpt-4.1「内置」、支持的档位写「不支持思考」；glm-5.1「未确认」、档位 low / medium / high；每行有「覆盖」。
- 操作：点 gpt-5.6-sol 的「覆盖」，取消勾选 xhigh，保存，再点「保存更改」。
- 预期：这一行来源变成「已覆盖」，档位只剩 low / medium / high，操作变成「修改」「恢复内置」；auto-gpt 困难档原来存的「跟随打分 medium～xhigh」那一格标黄，下面写「超出模型能力，实际按 high 发送」。

**用例（边界 / 异常）**
- 场景：还没有任何虚拟模型。
- 预期：「模型思考能力」卡片显示空状态「还没有虚拟模型用到的模型」。
- 场景：点已覆盖行的「恢复内置」，再点「保存更改」。
- 预期：这一行回到「内置」，档位回到内置值。

## 约束
- C1：new-api 内置一份模型思考能力表，只收 2026 年发布的模型，覆盖 OpenAI、Claude、Gemini、DeepSeek、GLM 五个家族，按模型名匹配；2025 年及以前发布的模型不收，按「未确认」处理。例外：已确认「不支持思考」的老模型（例如 gpt-4o、gpt-4.1、gpt-4.1-mini、gemini-2.5-flash-image）照样收录，避免给不会思考的模型发思考参数。每个模型记「不支持思考」，或者支持七档（none / minimal / low / medium / high / xhigh / max）里的哪几档；发布日期和取值都以各厂商官方文档为准，代码里写明来源链接。官方文档没写档位的模型（例如 glm-5、glm-5.1）不收。
- C2：内置表里没有、管理员也没覆盖的模型 →「未确认」，当成只支持 low / medium / high。
- C3：管理员覆盖的值优先于内置值；覆盖可以针对任何模型，包括内置表里没有的。覆盖值是「不支持思考」或七档里至少一档。
- C4：「虚拟模型」卡片下面新增「模型思考能力」卡片：标题后面显示模型数量，说明文字「智能路由按这里的信息决定能发哪些思考力度。内置值来自各厂商官方文档，可以按模型覆盖。」，下面是表格。
- C5：表格只列所有虚拟模型三个档位里用到的模型，同一个模型只列一行；打分模型和顾问模型不列。列依次是：模型、来源、支持的档位、操作。
  - 来源用小标签：「内置」灰色，「已覆盖」主色，「未确认」黄色。
  - 支持的档位每档一个小标签；不支持思考时写「不支持思考」；「未确认」的行，档位小标签用描边样式。
  - 操作：没覆盖过的行只有「覆盖」；已覆盖的行有「修改」和「恢复内置」。
- C6：没有任何虚拟模型时，卡片显示空状态「还没有虚拟模型用到的模型」。
- C7：点「覆盖」或「修改」打开弹窗「覆盖 <模型> 的思考能力」，说明「勾选这个模型支持的思考力度，保存更改后生效。」；内容是一个「不支持思考」开关和七档勾选框，打开时填好当前生效的值。打开「不支持思考」后勾选框变灰不能选。底部「取消」「保存」。没打开「不支持思考」又一档都没勾就点「保存」→ 弹窗不关，写红字「至少选择一个档位」。
- C8：覆盖、修改、恢复内置都要点页面右上角「保存更改」才生效，和虚拟模型的改动一起保存。
- C9：某个档位存的力度（固定值，或跟随打分的最低、最高）超出这个模型当前的能力 →「虚拟模型」表格里那一格的力度文字标黄，下面多一行黄色小字「超出模型能力，实际按 <实际发送的档位> 发送」。存的配置不自动改。
- C10：配置弹窗里档位的力度下拉只列模型当前支持的档位；模型「未确认」时力度那一行末尾显示黄色小标签「能力未确认」，悬停提示「内置能力表里没有这个模型，可在「模型思考能力」里补充」；模型不支持思考时，力度那一行换成灰字「该模型不支持思考力度，请求时不发送思考参数」。
- C11：卡片和弹窗里所有新增文字都有 en、zh、zh-TW、fr、ru、ja、vi 七种语言的翻译。

## 验证路径
1. 配好 auto-gpt、auto-chat → 打开智能路由页，「模型思考能力」列出 5 个模型，来源和档位如用例所示。
2. 覆盖 gpt-5.6-sol 去掉 xhigh，保存更改 → 来源变「已覆盖」，auto-gpt 困难档那一格标黄。
3. 点「恢复内置」并保存更改 → 回到内置值，标黄消失。
4. 拿实际页面和确认过的预览逐项对比：卡片、表格、空状态、覆盖弹窗、标黄提示。
