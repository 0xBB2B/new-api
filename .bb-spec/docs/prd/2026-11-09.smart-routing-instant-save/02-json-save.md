# JSON 视图的保存按钮

## 用户故事
### P0：作为管理员，我想在 JSON 视图改完直接在框下面点「保存」，以便不用去页面别处找保存按钮

**用例（主路径）**
- 场景：管理员切到「JSON」视图，配置里 auto-gpt 的困难档是 gpt-5.6-sol。
- 操作：把困难档模型改成 gpt-5.5，点 JSON 框下方的「保存」。
- 预期：顶部提示「保存成功」，页面停在 JSON 视图，「保存」变回灰色；切回可视化，困难档显示 gpt-5.5；刷新后不变。

**用例（边界 / 异常）**
- 场景：刚切到 JSON 视图，什么都没改。
- 预期：「保存」是灰的，不能点。
- 场景：把困难档改成在 api 分组没有渠道的模型。
- 操作：点「保存」。
- 预期：顶部弹出和现在一样的检查错误，什么都不提交，改动留在框里。
- 场景：在 JSON 里改了困难档还没保存。
- 操作：点「可视化」。
- 预期：弹出「放弃未保存的修改？」。点「取消」→ 留在 JSON，改动还在；点「放弃修改」→ 切回可视化，表格显示已保存的配置。

## 约束
- C1：JSON 视图里，JSON 编辑框下方靠右有一个「保存」按钮（28px 高的主色按钮）。可视化视图里不显示这个按钮。
- C2：JSON 内容和已保存的配置一样时，「保存」变灰不能点。只改了空格、换行，或者点了「格式化 JSON」，也算一样。内容不一样时（包括写成了不合法的 JSON），「保存」能点。
- C3：点「保存」时，按现在 JSON 视图保存的规则检查：JSON 写错、名称重复、模型在分组里没有渠道等等。不通过就在顶部弹出原因，什么都不提交，框里的内容保持不变。
- C4：检查通过后只提交虚拟模型配置。提交中「保存」变灰并显示「正在保存...」，JSON 编辑框和「可视化」「JSON」两个标签也不能操作。成功后顶部提示「保存成功」，停在 JSON 视图，「保存」变回灰色；切回可视化看到的是刚保存的配置。
- C5：提交失败时（网络错误或后台拒绝），顶部弹出失败原因，框里的内容保持不变，「保存」恢复可点，可以直接再点重试。
- C6：JSON 内容和已保存的配置不一样时点「可视化」，弹出确认框：标题「放弃未保存的修改？」，说明"JSON 里的改动还没保存，切回可视化会丢掉这些改动。"，按钮「取消」和「放弃修改」。点「取消」留在 JSON，内容不变；点「放弃修改」丢掉改动，切回可视化，显示已保存的配置。
- C7：JSON 内容和已保存的配置一样时点「可视化」，直接切换，不弹确认框。
- C8：在 JSON 视图里，「添加虚拟模型」按钮和现在一样是灰的。

## 验收
- [ ] C1：切到 JSON → 编辑框下方靠右出现「保存」；切回可视化 → 没有这个按钮。
- [ ] C2：刚切到 JSON →「保存」是灰的；只加几个空格、换行，或点「格式化 JSON」→ 仍是灰的；改掉一个模型名 → 能点；删掉一个右括号 → 能点。
- [ ] C3：删掉一个右括号再点「保存」→ 弹出 JSON 格式错误，刷新后配置没变；把困难档改成在 api 分组没有渠道的模型再点「保存」→ 弹出对应的检查错误，什么都不提交。
- [ ] C4：把困难档改成 gpt-5.5，点「保存」→ 提交中按钮显示「正在保存...」，编辑框不能输入，两个标签点不动；成功后出现「保存成功」，停在 JSON，「保存」变灰；切回可视化，困难档是 gpt-5.5；后台的思考能力覆盖没变。
- [ ] C5：断网后点「保存」→ 出现错误提示，内容还在，「保存」能点；恢复网络再点 → 成功。
- [ ] C6：改了内容没保存就点「可视化」→ 弹出「放弃未保存的修改？」；点「取消」→ 留在 JSON，改动还在；再点「可视化」→「放弃修改」→ 切回可视化，表格显示已保存的配置。
- [ ] C7：没改内容就点「可视化」→ 直接切换，没有确认框。
- [ ] C8：在 JSON 视图里，「添加虚拟模型」是灰的。

## 验证路径
1. 切到 JSON →「保存」是灰的。
2. 点「格式化 JSON」→ 仍是灰的；把困难档改成 gpt-5.5 →「保存」能点。
3. 点「可视化」→ 弹出确认框；点「取消」→ 留在 JSON。
4. 点「保存」→ 出现「保存成功」，按钮变灰；切回可视化，困难档是 gpt-5.5；刷新后不变。
5. 再切到 JSON，删掉一个右括号点「保存」→ 弹出错误，刷新后配置没变。
