# 可视化操作立即保存

## 用户故事
### P0：作为管理员，我想在弹窗里点「保存」就让配置生效，以便不用再找第二个保存按钮，也不会因为忘点而丢掉改动

**用例（主路径）**
- 场景：管理员打开「系统设置 → 请求策略 → 智能路由」，已有虚拟模型 auto-gpt，困难档是 gpt-5.6-sol。
- 操作：点 auto-gpt 那一行的编辑按钮，把困难档模型换成 gpt-5.5，点弹窗里的「保存」。
- 预期：弹窗关闭，表格里困难档显示 gpt-5.5，顶部提示「保存成功」。刷新页面后困难档仍是 gpt-5.5，之后的请求按 gpt-5.5 路由。

**用例（边界 / 异常）**
- 场景：编辑弹窗里的检查都通过了，但提交时网络断了。
- 操作：点「保存」。
- 预期：弹窗不关，填的内容都在，顶部弹出错误原因。网络恢复后再点「保存」→ 保存成功，弹窗关闭。
- 场景：删除 auto-gpt。
- 操作：点那一行的「⋯」→「删除」，确认框里点「删除」。
- 预期：确认框写"确定删除 auto-gpt 吗？确认后立即生效。"，点「删除」后这一行消失，顶部提示「保存成功」。删掉的是最后一个虚拟模型时，显示"还没有虚拟模型"的空状态。

### P0：作为管理员，我想覆盖、修改、恢复模型思考能力后立即生效，以便和虚拟模型的改动一样不用再点保存

**用例（主路径）**
- 场景：「模型思考能力」表里 gpt-5.6-sol 的来源是「内置」。
- 操作：点「覆盖」，取消勾选 xhigh，点「保存」。
- 预期：弹窗关闭，来源变成「已覆盖」，顶部提示「保存成功」，刷新后不变。

**用例（边界 / 异常）**
- 场景：gpt-5.6-sol 的来源是「已覆盖」。
- 操作：点「恢复内置」。
- 预期：不弹确认框，直接提交。来源变回「内置」，顶部提示「保存成功」，刷新后不变。

## 约束
- C1：智能路由页的页面标题右边不显示「保存更改」按钮。系统设置里其他分区的保存按钮不变。
- C2：添加、编辑弹窗里点「保存」时，先按现在的规则逐项检查；有错时和现在一样，弹窗不关、标红字，什么都不提交。全部通过后立即提交，提交成功后弹窗关闭，表格显示新值，顶部提示「保存成功」。
- C3：删除确认框的说明是"确定删除 <名称> 吗？确认后立即生效。"。点「删除」后立即提交，成功后确认框关闭，这一行消失，顶部提示「保存成功」。
- C4：思考能力覆盖弹窗（「覆盖」「修改」打开的弹窗）的说明是"勾选这个模型支持的思考力度，保存后立即生效。"。点「保存」时，先做现在的检查（没打开「不支持思考」又一档都没勾，就写「至少选择一个档位」，弹窗不关）；通过后立即提交，成功后弹窗关闭，来源变成「已覆盖」，顶部提示「保存成功」。
- C5：点「恢复内置」不弹确认框，立即提交。成功后来源变回「内置」，顶部提示「保存成功」。
- C6：一次操作只提交它改的那一项：改虚拟模型时只提交虚拟模型配置，改思考能力时只提交思考能力覆盖，另一项在后台保持原值。
- C7：提交过程中，弹窗或确认框里的「取消」和保存类按钮都变灰不能点，保存类按钮显示「正在保存...」。
- C8：提交失败时（网络错误或后台拒绝），弹窗或确认框不关，填的内容都保留，顶部弹出失败原因；表格保持提交前的值。管理员可以直接再点一次保存类按钮重试。「恢复内置」失败时只弹出失败原因，来源保持「已覆盖」。
- C9：提交成功后刷新页面，看到的是刚保存的值。

## 验收
- [ ] C1：打开智能路由页 → 标题右边没有「保存更改」按钮；打开「请求策略」下其他分区（如「重试」）→ 右上角保存按钮还在，行为不变。
- [ ] C2：编辑 auto-gpt，把困难档换成在 api 分组没有渠道的模型再点「保存」→ 出现红字，弹窗不关，刷新后配置没变。改成 gpt-5.5 再点「保存」→ 弹窗关闭，表格显示 gpt-5.5，出现「保存成功」。添加虚拟模型 auto-claude 同样一次保存就出现在表格里。
- [ ] C3：删除 auto-gpt → 确认框说明是"确定删除 auto-gpt 吗？确认后立即生效。"；点「删除」→ 这一行消失，出现「保存成功」，刷新后仍然没有这一行。
- [ ] C4：覆盖 gpt-5.6-sol → 弹窗说明是"勾选这个模型支持的思考力度，保存后立即生效。"；全部不勾就保存 → 出现「至少选择一个档位」，弹窗不关；去掉 xhigh 保存 → 来源「已覆盖」，出现「保存成功」。
- [ ] C5：对「已覆盖」的模型点「恢复内置」→ 没有确认框，来源变回「内置」，出现「保存成功」。
- [ ] C6：先覆盖 gpt-5.6-sol 并保存，再编辑 auto-gpt 并保存 → 后台的思考能力覆盖仍然保留 gpt-5.6-sol 的覆盖；反过来先改虚拟模型再恢复内置 → 虚拟模型配置不变。
- [ ] C7：让提交慢下来（比如开浏览器的网络限速）后点弹窗「保存」→ 提交完成前「取消」和「保存」都是灰的，「保存」显示「正在保存...」。
- [ ] C8：断网后在编辑弹窗点「保存」→ 弹窗不关、内容还在、出现错误提示，表格还是旧值；恢复网络再点「保存」→ 成功。断网后点「恢复内置」→ 出现错误提示，来源仍是「已覆盖」。
- [ ] C9：完成 C2～C5 中任一项后刷新页面 → 显示的是刚保存的值。

## 验证路径
1. 打开智能路由页 → 标题右边没有「保存更改」。
2. 编辑 auto-gpt，把困难档换成 gpt-5.5，点「保存」→ 弹窗关闭，出现「保存成功」；刷新后仍是 gpt-5.5。
3. 覆盖 gpt-5.6-sol，去掉 xhigh，点「保存」→ 来源「已覆盖」；点「恢复内置」→ 来源「内置」；刷新后是「内置」。
4. 断网后编辑 auto-gpt 并保存 → 弹窗不关、出现错误提示；恢复网络再点「保存」→ 成功。
5. 删除 auto-gpt → 确认后这一行消失；刷新后仍然没有。
