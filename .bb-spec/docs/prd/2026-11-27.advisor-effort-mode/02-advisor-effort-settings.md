# 后台设置顾问的力度方式

## 用户故事
### P0：作为管理员，我想要在路由编辑窗口里给顾问设思考力度方式，以便不用手写路由 JSON

**用例（主路径）**
- 场景：管理员在「系统设置 → 请求策略 → 智能路由」编辑虚拟模型 auto-gpt，顾问模型是 gpt-6.2-astra（支持 low、medium、high、xhigh、max）。
- 操作：切到左侧「顾问」标签，在「思考力度」行点「跟随打分」，最低选 medium、最高选 max，点「保存」。
- 预期：窗口关闭，回到列表，顶部弹出「保存成功」；auto-gpt 这一行「顾问」列第二行写「跟随打分 medium～max · 连续 2 次不满意」。

**用例（校验出错）**
- 场景：同上。
- 操作：最低选 max、最高选 medium，点「保存」。
- 预期：窗口不关闭；「最高」下拉红框，行下红字「最低力度不能高于最高力度」；左侧「顾问」标签名字后出红点，摘要变红，多一行「1 个错误」。

### P0：作为管理员，我想要不打开窗口也能看到顾问设了什么力度，以便检查各虚拟模型的配置

**用例（主路径）**
- 场景：列表里有 4 个虚拟模型，顾问力度分别是不覆盖、固定 high、跟随打分 medium～max、顾问模型不支持思考。
- 操作：打开智能路由页。
- 预期：「顾问」列第二行依次是「不覆盖 · 连续 2 次不满意」「固定 high · 连续 3 次不满意」「跟随打分 medium～max · 连续 2 次不满意」「不支持思考 · 连续 2 次不满意」。

**用例（力度超出模型能力）**
- 场景：顾问力度是「固定 max」，顾问模型最高只支持 high。
- 操作：打开智能路由页。
- 预期：「顾问」列的力度摘要「固定 max」变黄色，下面多一行黄字「超出模型能力，实际按 high 发送」。

## 约束
- C1 布局：路由编辑窗口的顾问面板从上到下依次是「顾问模型」「思考力度」「连续不满意几次后交给顾问」「分组顺序」四行。「思考力度」是新增的一行，其余三行的位置、文案和行为不变。
- C2 「思考力度」一行的控件、文案、说明气泡和三个档位面板的「思考力度」一行完全一样：
  - 三个方式按钮：不覆盖 / 固定 / 跟随打分；
  - 「固定」时后面一个档位下拉，没选时显示灰色「选择」；
  - 「跟随打分」时后面是「最低」下拉 ～「最高」下拉，没选时都显示「选择」；
  - 下拉只列顾问模型支持的档位（gpt-6.2-astra 列 low、medium、high、xhigh、max）；
  - 说明图标的气泡文字和档位面板的相同。
- C3 默认值：添加窗口里，以及编辑一个顾问设置没有力度方式的已有路由时，「不覆盖」选中，后面没有下拉。
- C4 切换方式：
  - 点「不覆盖」→ 后面的下拉消失，已选的档位清空；
  - 点「固定」→ 出现一个档位下拉，最低、最高清空；
  - 点「跟随打分」→ 出现「最低 ～ 最高」两个下拉，固定档位清空。
- C5 顾问模型的思考能力决定这一行怎么显示，和档位面板一样：
  - 顾问模型不支持思考 → 整行变灰，没有按钮，只显示「该模型不支持思考力度，请求时不发送思考参数」；切换到不支持思考的顾问模型时，已选的力度设置清空；
  - 能力未确认 → 按钮和下拉可用，下拉只列 low、medium、high，行尾黄色徽标「能力未确认」，悬停出气泡「这个模型还没有配置思考等级，可在「模型管理」里编辑这个模型，在「模型能力」里补充」；
  - 能力加载中 → 三个方式按钮变灰不能点，不显示下拉；
  - 能力加载失败 → 三个方式按钮变灰不能点，不显示下拉，行尾红字「思考能力加载失败」。
- C6 保存时的校验和档位一样，不通过时窗口不关闭：
  - 「固定」没选档位 → 下拉红框，一行红字「请选择有效的思考力度」，左侧「顾问」标签显示「1 个错误」；
  - 「跟随打分」两个下拉都没选 → 两个下拉红框，两行红字「请选择有效的思考力度」，左侧标签显示「2 个错误」；
  - 「跟随打分」最低高于最高 → 「最高」下拉红框，红字「最低力度不能高于最高力度」，左侧标签显示「1 个错误」；
  - 有错误时，左侧「顾问」标签名字后出红点，摘要变红。
- C7 左侧「顾问」标签的第二行是「模型名 · 力度摘要」，写法和「打分」标签一样；力度摘要是「不覆盖」「固定 high」「跟随打分 medium～max」「不支持思考」之一；还没选顾问模型时写「未设置」。摘要放不下时省略成「gpt-6.2-astra · 跟…」，鼠标移上去出气泡显示全文。
- C8 列表「顾问」列：第一行是顾问模型名；第二行灰色小字是「力度摘要 · 连续 N 次不满意」，力度摘要的四种写法同 C7；放不下时省略，鼠标移上去显示全文。
- C9 顾问设的力度超出顾问模型能力时（会被换档），列表「顾问」列的力度摘要变黄色，下面多一行黄字「超出模型能力，实际按 <实际档位> 发送」，和档位列的写法一样。
- C10 界面文字支持多语言，新增的文案在七种语言文件里都有翻译。

## 验收
- [ ] C1：打开编辑窗口切到「顾问」→ 四行依次是顾问模型、思考力度、连续不满意几次后交给顾问、分组顺序。
- [ ] C2：顾问模型 gpt-6.2-astra，点「固定」展开下拉 → 列出 low、medium、high、xhigh、max；说明气泡文字和「简单档」面板的相同。
- [ ] C3：打开添加窗口 → 「不覆盖」选中、没有下拉；编辑一个顾问设置没有力度方式的已有路由 → 「不覆盖」选中。
- [ ] C4：「固定」选 high 后点「不覆盖」→ 下拉消失；再点「固定」→ 下拉显示「选择」。「跟随打分」选好范围后点「固定」→ 只剩一个显示「选择」的下拉。
- [ ] C5：顾问模型换成不支持思考的模型 → 整行变灰，显示「该模型不支持思考力度，请求时不发送思考参数」，保存后顾问力度设置为空；换成能力未确认的模型 → 下拉只列 low、medium、high，行尾有「能力未确认」徽标；能力接口失败 → 按钮不能点，行尾红字「思考能力加载失败」。
- [ ] C6：三种出错情况分别点「保存」→ 窗口不关闭，红框、红字、左侧标签红点与「N 个错误」和约束一致。
- [ ] C7：「跟随打分」medium～max → 左侧「顾问」标签第二行显示省略后的「gpt-6.2-astra · 跟…」，悬停气泡显示「gpt-6.2-astra · 跟随打分 medium～max」；没选顾问模型 → 显示「未设置」。
- [ ] C8：四种力度设置的路由 → 列表「顾问」列第二行分别是「不覆盖 · 连续 2 次不满意」「固定 high · 连续 3 次不满意」「跟随打分 medium～max · 连续 2 次不满意」「不支持思考 · 连续 2 次不满意」。
- [ ] C9：顾问「固定 max」、模型最高支持 high → 顾问列「固定 max」黄色，下面黄字「超出模型能力，实际按 high 发送」。
- [ ] C10：切换到英文、日文界面 → 「思考力度」一行和顾问摘要的文字都显示成当前语言，没有夹杂未翻译的英文。

## 验证路径
1. 打开智能路由页，点「添加虚拟模型」，切到「顾问」→ 「思考力度」行「不覆盖」选中；左侧「顾问」标签写「未设置」。
2. 选顾问模型 gpt-6.2-astra，点「跟随打分」，不选范围直接保存 → 两行红字「请选择有效的思考力度」，左侧标签「2 个错误」。
3. 最低选 medium、最高选 max，填好其他必填项保存 → 「保存成功」；列表「顾问」列写「跟随打分 medium～max · 连续 2 次不满意」。
4. 再编辑它，鼠标移到左侧「顾问」标签 → 气泡显示「gpt-6.2-astra · 跟随打分 medium～max」。
5. 把顾问改成「固定 max」，顾问模型换成最高支持 high 的模型，保存 → 列表顾问列「固定 max」变黄，下面黄字「超出模型能力，实际按 high 发送」。
