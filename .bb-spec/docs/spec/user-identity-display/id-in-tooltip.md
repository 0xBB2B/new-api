# 用户 ID 进悬浮 tip

## 目的

排查问题时先看到「是谁」，再在需要精确定位时通过悬浮拿到唯一标识（用户名与 ID），主文本不被数字占据。

## 逻辑

1. 覆盖四处：数据看板（用户消耗排行与趋势图、流向图用户节点）、使用日志用户列、任务日志用户列、审计日志用户列与详情「操作者」行。
2. 主文本只显示用户名称（显示名优先，缺省回退用户名，再缺省为 `用户 {id}`），不并排显示 ID。
3. 鼠标悬浮主文本时弹出 tip，内容固定两行：
   - `用户名: {username}`（`username` 为空时该行不显示）
   - `用户 ID: {user_id}`
4. 使用日志、任务日志的「隐藏敏感信息」开关打开时，主文本为遮罩 `••••`，此时不弹 tip，不通过任何方式暴露用户名或 ID。
5. 看板图表的悬浮由图表自身的 tooltip 承担：排行/趋势图 tooltip 标签为 `名称 · 用户名 · ID:{id}`（名称与用户名相同时省略用户名段），坐标轴与图例只显示名称；流向图用户节点标签为名称。
6. 审计日志详情「操作者」行的值为名称，ID 与用户名放在同一行的悬浮 tip 中，不再以 `名称 (ID: x)` 形式内联。

## 约束

- 主文本区域不包含 `ID`、`#` 或裸数字形式的用户标识。
- tip 中「用户 ID」行永远存在且值为整数；「用户名」行仅在用户名非空时存在。
- 敏感隐藏模式下用户列 DOM 中不存在用户名与 ID 文本。
- 所有新增文案走前端 i18n，键为英文源串：`Username`、`User ID`、`User {{id}}`。

## 例子

使用日志中一条记录：`user_id=7, username=zhangsan, display_name=张三`。

- 用户列主文本：`张三`。
- 悬浮 tip：第一行 `用户名: zhangsan`，第二行 `用户 ID: 7`。
- 打开「隐藏敏感信息」后：主文本 `••••`，悬浮无 tip。
- 看板排行图：Y 轴显示 `张三`，tooltip 标签 `张三 · zhangsan · ID:7`。
- 审计日志详情：操作者行显示 `张三`，悬浮显示 `用户名: zhangsan` 与 `用户 ID: 7`。

## 验收

- [ ] 四处主文本均为名称，DOM 中不含 `(ID: 7)`、`#7`、`用户 7` 等 ID 形式（三字段全空的记录除外）。
- [ ] 悬浮 tip 含 `用户 ID: 7`；用户名非空时含 `用户名: zhangsan`，为空时无该行。
- [ ] 敏感隐藏模式下用户列无 tip 且 DOM 中不含 `zhangsan` 与 `7`。
- [ ] 看板排行/趋势图 tooltip 标签为 `张三 · zhangsan · ID:7`，坐标轴与图例为 `张三`；显示名等于用户名时标签为 `zhangsan · ID:7`。
- [ ] 审计日志详情操作者行主文本为名称，ID 仅在 tip 中出现。
