# 用户名称解析

## 目的

管理端各处展示用户时，用同一条规则从一条记录的 `display_name` / `username` / `user_id` 三个字段推导出唯一的主文本，避免各页面各自拼装、结果不一致。

## 逻辑

1. 输入是一条带用户信息的记录，可含三个字段：`display_name`（可空）、`username`（可空）、`user_id`（整数）。
2. 按顺序取第一个非空值作为主文本：
   - `display_name` 去除首尾空白后非空 → 取 `display_name`；
   - 否则 `username` 非空 → 取 `username`；
   - 否则 → 取 `用户 {user_id}`（走 i18n，英文为 `User {{id}}`）。
3. 主文本只包含一个名称，不把显示名与用户名并排写成 `a (b)` 或 `a (a)`。
4. 该规则只决定「显示什么」，不改变记录的分组、排序、筛选所依据的字段。

## 约束

- 主文本永远非空：三个字段的任意组合都有确定输出。
- `display_name` 仅由空白字符组成时视为空。
- 显示名与用户名相同时输出一次该名称，无重复。
- 同一条记录在看板、使用日志、任务日志、审计日志四处得到的主文本相同。

## 例子

| display_name | username | user_id | 主文本 |
|---|---|---|---|
| `张三` | `zhangsan` | 7 | `张三` |
| `  ` | `zhangsan` | 7 | `zhangsan` |
| `zhangsan` | `zhangsan` | 7 | `zhangsan` |
| 空 | 空 | 7 | `用户 7` |

## 验收

- [ ] 上表四组输入分别得到对应的主文本。
- [ ] 显示名为纯空白时按空处理，回退到用户名。
- [ ] 主文本中不出现括号并排的第二个名称。
- [ ] 看板、使用日志、任务日志、审计日志对同一条记录输出相同主文本。
