# 订阅用量进度条布局

## 目的
让管理员在渠道列表里一眼同时看到 Codex / Claude 订阅账号的 5 小时短窗口与 7 天长窗口用量，而不是只看到其中一个。

## 逻辑
- 数据来源：渠道 `other_info.subscription_usage` 快照，按现有窗口归类规则解析出 5 小时窗口与 7 天窗口。
- 两个窗口都存在 → 渲染两行，上行是 5 小时窗口，下行是 7 天窗口，两行垂直紧贴（行间距不超过 2px），三列对齐：
  1. 左列标签，5 小时窗口固定文本 `5h`，7 天窗口固定文本 `7d`，弱化色、小字号；
  2. 中列进度条，宽 80px、轨道高 6px，是每行的主信息；
  3. 右列整数百分比 `N%`，等宽数字，列宽固定为能容纳 `100%` 的宽度并左对齐，使不同位数的百分比起笔与进度条终点在各行间对齐。
- 只有一个窗口 → 渲染一行，列结构与两行时完全一致：左列标签按窗口类型显示 `5h` 或 `7d`，中列进度条，右列百分比。
- 无快照或两个窗口都不存在 → 显示 `-`，悬浮提示"无用量数据"。
- 每行进度条颜色按该行百分比分级：< 80% 信息色，80%～94% 警告色，≥ 95% 危险色。
- 每行百分比文字颜色：< 80% 用弱化灰色（与标签同色）；80%～94% 警告色；≥ 95% 危险色。低于告警线时只有进度条着色，数字退为注解。
- 每行进度条的 `aria-label` 为对应窗口名（5 小时窗口 / 每周窗口）+ 百分比。
- 整块悬浮提示保持现状：仅显示快照更新时间。

## 约束
- 标签 `5h` / `7d` 为固定英文缩写，不进 i18n。
- 不改变窗口归类、百分比夹取与分级阈值的现有逻辑。
- 单行与两行共用同一标签列宽、进度条宽度与百分比列宽，避免列表列宽跳动。

## 例子
- 快照：5 小时窗口 `used_percent: 29`，7 天窗口 `used_percent: 31` → 两行，上行 `5h ▬▬ 29%`，下行 `7d ▬▬ 31%`，两行进度条均为信息色，两行百分比均为弱化灰色。
- 快照：5 小时窗口 `used_percent: 96`，7 天窗口 `used_percent: 40` → 上行进度条与 `96%` 为危险色，下行进度条为信息色、`40%` 为弱化灰色。
- 快照：仅 7 天窗口 `used_percent: 88` → 单行 `7d ▬▬ 88%`，进度条与 `88%` 均为警告色。
- 快照：仅 5 小时窗口 `used_percent: 12` → 单行 `5h ▬▬ 12%`，进度条信息色、`12%` 弱化灰色。
- 三条渠道分别为 `7%`、`40%`、`100%` → 三行的进度条左右缘各在同一垂直线上，百分比起笔紧贴条尾对齐。
- `other_info` 为空 → 显示 `-`，悬浮提示"无用量数据"。

## 验收
- [ ] 两窗口并存时渲染两行，顺序 5h 在上、7d 在下，各自百分比正确。
- [ ] 两行的颜色分级互不影响，按各自百分比计算；< 80% 时进度条为信息色而百分比文字为弱化灰色，≥ 80% 时二者同为警告/危险色。
- [ ] 只有一个窗口时是单行且标签与窗口类型对应（5 小时 → `5h`，7 天 → `7d`）；无快照时显示 `-`。
- [ ] 每行百分比位于进度条之后，固定宽度左对齐；不同位数的百分比在各行间起笔对齐。
- [ ] 进度条宽 80px、轨道高 6px；两行紧贴，标签列宽、进度条宽度与百分比列宽和单行一致。
