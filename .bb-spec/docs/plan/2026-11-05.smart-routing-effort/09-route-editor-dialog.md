# 虚拟模型编辑弹窗改版

## 目标
「添加 / 编辑虚拟模型」弹窗按确认过的预览重做，一次只显示一组设置，关键字段一屏看完，出错时自动切到第一个有错的地方。

## 业务规则（来源：PRD 04-editor-layout，界面以确认过的预览为准）
- C1：`max-w-5xl`。顶部一行只有「名称」（必填）和「接口」。接口是三个可多选的切换按钮 Responses · Chat · Anthropic（ToggleGroup multiple，outline、sm），选中样式主色描边 + 浅底 + 主色字（照 `channel-priority-controls.tsx:192` 那组 class）；悬停显示完整路径（Responses 的提示写明压缩请求 `/v1/responses/compact` 跟着它）。ⓘ：「客户端可以用勾选的任一种格式请求这个虚拟模型，其他格式返回 400；格式转换由渠道完成。至少选一种」。
- C2：下面左右两栏（`md:grid-cols-[9.5rem_minmax(0,1fr)]`）。左栏竖排 Tab「打分」「档位」「顾问」，每个写名字 + 一行摘要（07 的 `slotSummaries`），选中用和接口按钮相同的主色样式；方向键切换，读屏读作标签页（role=tablist / tab）。手机宽度左栏变顶部横排。
- C3：右栏每行左边字段名、右边控件；说明一律放字段名旁 ⓘ（照 `features/dashboard/components/flow/flow-charts.tsx:555` 的小按钮 + Info 图标 + Tooltip）。框里只留出错红字和「该模型不支持思考力度，请求时不发送思考参数」。
- C4「打分」：打分模型（ⓘ「用户每发一条新消息调用一次。费用按打分模型的价格，单独记一条消费记录」）、超时（毫秒）（ⓘ「超时就用默认档」）、分组顺序。
- C5「档位」：顶部一行左边三档切换（Tabs default 变体）「简单 · <模型>」「普通 · <模型>」「困难 · <模型>」，默认档后面带 Badge outline「默认」，悬停显示「<模型> · <力度摘要>」；右边小下拉「默认档」（ⓘ「下面 4 种情况都用默认档：打分失败或超时；打分把握不足；工具续跑时没有会话；选中的档位没有渠道」），默认普通档。下面三行：<档>模型（ⓘ「用户每发一条新消息，打分后落到其中一档」）、思考力度、分组顺序。
- C6 思考力度一行：ToggleGroup 三选一「不覆盖 · 固定 · 跟随打分」；固定 → 后面一个小下拉；跟随打分 → 「[最低] ～ [最高]」两个小下拉（原生下拉 sm、`w-28`）。下拉只列有效能力里的档位；未确认 → 行末 Badge warning「能力未确认」，悬停「内置能力表里没有这个模型，可在「模型思考能力」里补充」；不支持思考 → 整行换成灰字。ⓘ：「不覆盖：保留客户端传来的值，模型不支持这一档时自动换成最接近的档位。跟随打分：按打分的「要想多深」取值（低→low、中→medium、高→high），再限制在最低和最高之间；打分失败时用最高。力度下拉只列这个模型支持的档位」。
- C7「顾问」：顾问模型（ⓘ「同一段对话里，用户连续多条消息表示不满意时，这一轮交给顾问模型回答」）、连续不满意几次后交给顾问、分组顺序。没有力度。
- C8：「高级设置」收起，放在整个弹窗最底部横跨两栏，字段同一期。底部「取消」「保存」。
- C9：三个 Tab 的分组顺序都用 08 的紧凑样式；分组出错时这一行描红并在下面写红字（含 05 的格式检查错误）。
- C10：打开弹窗（新建或编辑）停在「打分」；新建时接口只选 Responses、分组为空。
- C11：保存时把后端返回的错误按字段放到对应位置；有错的左栏 Tab 带红点和「<N> 个错误」，档位里有错的那一档也带红点；自动切到第一个有错的地方，顺序：打分 → 档位（简单 → 普通 → 困难）→ 顾问。名称、接口的错误写在顶部各自下面，不加左栏红点。
- C12：1100px 高的窗口里每个 Tab 不用滚动就能看全。
- C14：新增文字七种语言都有翻译（含 05 的后端错误英文原文键）。

## 函数清单
### route-editor-dialog.tsx（及拆出的同目录组件）
| 函数名 | 职责 |
|---|---|
| `RouteEditorDialog` | 整体布局、Tab 状态、保存与错误分发、自动切到第一个有错的地方 |
| `ScorerPanel` / `TiersPanel` / `AdvisorPanel` | 三个 Tab 的右栏表单 |

| `firstErrorLocation` | 由错误字段列表得出要切到的 Tab 和档位 |
