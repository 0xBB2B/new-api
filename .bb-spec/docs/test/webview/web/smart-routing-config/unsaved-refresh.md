# 弹窗保存后不点保存更改就刷新
## 简介
编辑已有的 auto-gpt，把「连续不满意几次后交给顾问」从 2 改成 3，弹窗保存后表格先显示新值；不点「保存更改」直接刷新页面。
## 测试目的
PRD 05-config-page 验收 C8：弹窗保存后不点「保存更改」就刷新页面，改动不生效（点了才生效由 add-and-save 覆盖）。
